# 趣学汉语 · 教师端上线指引（阶段 0+1 傻瓜版）

> 写给芬芬：不用懂代码，照着做就行。这一步是给网站"打地基"——建好老师建班、发任务需要的数据库，并在注册页加上"我是老师 / 学生"的选择。

---

## 这一步总共要做 3 件事

1. 在 Supabase（你网站的数据库后台）跑一段我写好的 SQL，建好"班级 / 任务"需要的表。
2. 注册页已经加上"我是老师 / 学生"的选择（代码已改好）。
3. 把你自己的账号标记为"老师"。

> 说明：第 1、3 步需要你在 Supabase 后台点一下——因为涉及改线上数据库，我没有后台权限，不能替你执行，必须由你本人操作（这也是安全设计）。

---

## 第 1 步：打开 Supabase 后台

1. 浏览器打开并登录：**https://supabase.com/dashboard**（用你注册 Supabase 时那个账号）
2. 进入你的项目（对应趣学汉语网站，项目 ref：`yiicvtzauhzsszunwwms`）
3. 左侧菜单点 **SQL Editor** → 点 **New query**（新建一个空白查询）

---

## 第 2 步：粘贴并运行 SQL

1. 找到我准备好的文件：`app/supabase/teacher_features.sql`（已在你的网站代码里）
2. 打开它，**全选复制**全部内容，粘贴到刚才的 SQL Editor 空白查询里
3. 点右上角 **Run** 按钮（或按 `Ctrl/Cmd + Enter`）
4. 看底部的 **Messages** 面板，出现下面这行就成功了：

   ```
   ✅ 教师端表已就绪！
   classes / class_members / tasks / task_submissions 已创建
   ```

> 放心：这段 SQL 只**新建表 + 给现有用户表加一个 role 字段**，不会删除或改动你任何现有数据。即使重复跑也不会出错（都是"如果不存在才建"）。

---

## 第 3 步：把你的账号设为「老师」

两种方式，**任选一种**：

- **方式 A（推荐，最干净）**：重新注册一个老师账号。打开网站注册页，会多出一个「我要注册为：👨‍🎓学生 / 👩‍🏫老师」的选择，选"老师"注册即可——系统会自动把你标记成老师。
- **方式 B（沿用现有账号）**：在刚才的 SQL Editor 里，翻到 `teacher_features.sql` **最末尾**，有一行被注释掉的：
  ```sql
  -- UPDATE public.profiles SET role = 'teacher' WHERE email = '你的邮箱@example.com';
  ```
  把 `你的邮箱@example.com` 改成你自己的登录邮箱，然后**删掉开头的 `-- `**（两个减号加一个空格），再点一次 **Run**。

---

## 第 4 步：让网站用上新代码（上线）

注册页的代码已经改好，但要让**线上站**看到，需要部署一次。两种办法：

- **让 AI 帮你推**：直接对我说"帮我推上线"，我会在 WorkBuddy 里执行 `git push`，Vercel 会自动重新部署。
- **你自己来**：打开 Git Bash，进入网站目录，依次执行：
  ```bash
  git add -A
  git commit -m "教师端：注册页加学生/老师角色"
  git push
  ```
  Vercel 检测到推送会自动构建部署（通常 1–2 分钟）。

---

## 第 5 步：验证是否成功

- 打开网站注册页，应该能看到「我要注册为：👨‍🎓学生（来学汉语）/ 👩‍🏫老师（建班发任务）」两个大按钮。
- 用老师账号登录后，目前**还没有**"老师面板"入口——那是阶段 2 的功能（建班、发任务、看进度）。地基打完，下一步才做面板。

## 常见问题

**Q：跑 SQL 时报 "already exists" 之类的错？**
A：正常，SQL 是幂等的，可放心重复跑，忽略这类提示即可。

**Q：跑 SQL 提示没权限？**
A：确认你登录的是这个 Supabase 项目的 **owner（所有者）** 账号。

**Q：注册页看不到"我是老师"选项？**
A：代码改了但还没部署上线。请先完成第 4 步（部署）。本地临时预览可让我帮你跑 `npm run dev`。

**Q：能不能先不部署，只在我自己电脑看效果？**
A：可以。让我帮你在本地 `npm run dev` 起一个预览，注册页的"我是老师"选项就能立刻看到（数据库那步仍需要在 Supabase 后台跑）。
